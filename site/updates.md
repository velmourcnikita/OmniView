# Обновления

Открой настройки и нажми «Проверить обновления». Программа показывает готовую версию и последний коммит в GitHub. Проверку при запуске можно выключить; для работы класса интернет не требуется.

## Установка

1. Нажми «Загрузить обновление».
2. Дождись проверки файлов.
3. Заверши класс или выйди из подключения.
4. Нажми «Установить и перезапустить».

Загрузчик проверяет SHA-256 каждого файла по данным GitHub. При несовпадении установка не начинается. Если файлы заняты другой копией программы, закрой её и повтори. Предыдущие файлы сохраняются в папке обновления, настройки остаются на месте.

Для загрузки обновления папка программы должна быть доступна для записи. Обновляется комплект обеих ролей, подходящий архитектуре установленной программы.

## Новые коммиты

Параметр «Сборки новых коммитов» включает тестовый канал. После изменения основной ветки GitHub сначала запускает сборку и тесты. Только успешный запуск публикует готовые файлы в релизе `preview`.

Последний коммит и последняя готовая сборка могут различаться: проверка ещё выполняется или завершилась ошибкой. Исходники коммита не исполняются вместо программы. По умолчанию выбран обычный канал опубликованных версий.

## Portable

Приложение запускается из распакованной папки. Для переноса настроек вместе с программой создай рядом с EXE пустой файл `portable.flag`. Настройки, отчёты и профиль интерфейса будут храниться в `data` рядом с EXE. Если файла нет, используется профиль Windows.

В GitHub публикуются исходники и файлы программы. Презентации, материалы конкурса и полные проектные архивы туда не загружаются.
