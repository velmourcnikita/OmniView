# OmniView Legacy

Отдельная версия для старых Windows, Linux и macOS. Исходники и сборки находятся в [репозитории omniview-legacy](https://github.com/velmourcnikita/omniview-legacy).

В Windows Legacy использует обычные системные окна. Linux и macOS получают отдельный интерфейс без браузерного движка. Устанавливать браузерный компонент для интерфейса не нужно. Основная версия OmniView для Windows 10/11 сохраняет свой интерфейс.

## Какую версию выбрать

| Компьютер | Версия |
| --- | --- |
| Windows 10/11 | [OmniView](/download) |
| Windows 7 SP1, 8, 8.1 | [OmniView Legacy](https://github.com/velmourcnikita/omniview-legacy/releases) |
| Linux x64, glibc 2.35+ | [Legacy для Linux](https://github.com/velmourcnikita/omniview-legacy/releases) |
| macOS 11+ Intel / Apple Silicon | [Legacy для macOS](https://github.com/velmourcnikita/omniview-legacy/releases) |
| Windows XP/Vista, BSD, Linux musl/ARM | Сборок нет |

Выбирай x86 для 32-битной Windows, x64 — для 64-битной. Разрядность сборки сама по себе не обеспечивает совместимость со старой Windows.

## Ошибка ProcessPrng

Сообщение «Точка входа в процедуру ProcessPrng не найдена в библиотеке bcryptprimitives.dll» возникает при запуске современной сборки на системе, где нет нужного вызова. Скачай Legacy целиком. Подменять системную DLL не требуется.

Legacy собирается со стандартной библиотекой, рассчитанной на Windows 7, и другим системным источником случайных чисел. Это отдельная сборка, а не переименованный x86-файл основной версии.

## Подключение

Учитель и ученик могут использовать разные версии: Legacy сохраняет защищённый код класса OV3 и сетевой протокол основной программы. Ученик сам включает показ экрана, проверку списка процессов и управление.

У Legacy простой интерфейс: список учеников, экран выбранного компьютера, сообщения, задания, самостоятельная работа и обновления. Для удалённой помощи сначала нужен запрос учителя и согласие ученика. Esc останавливает управление.

## Portable и обновления

Создай пустой файл `portable.flag` рядом с EXE. Настройки и отчёты будут храниться в папке `data` рядом с программой. Папка должна быть доступна для записи.

Кнопка проверки обновлений обращается к отдельному репозиторию Legacy. Основная и старая версии не заменяют друг друга. Тестовый канал получает готовые сборки новых коммитов после успешных проверок.

## Проверка на старом компьютере

Сборки и тесты в современной Windows не заменяют запуск на Windows 7. До проверки на твоём компьютере совместимость остаётся экспериментальной. Legacy использует статическую библиотеку выполнения; отдельные Visual C++ DLL в этот комплект не входят. Интернет нужен только для получения обновлений; класс работает по локальной сети.

Основание для отдельных сборок: [целевые платформы Windows 7 в Rust](https://doc.rust-lang.org/rustc/platform-support/win7-windows-gnu.html), [окончание поддержки старых Windows в WebView2](https://blogs.windows.com/msedgedev/2022/12/09/microsoft-edge-and-webview2-ending-support-for-windows-7-and-windows-8-8-1/).

## Linux и macOS

Linux получает два исполняемых файла, macOS — образ DMG для Intel или Apple Silicon. Поддерживаются сообщения, запросы помощи, задания, отчёты и проверка точных имён процессов с согласием ученика. В Linux показ экрана доступен в X11; в Wayland пока недоступен. На macOS нужно разрешение на запись экрана.

Приём удалённого управления в Linux/macOS пока не реализован. Проверка последних коммитов есть, замена Unix-программы выполняется вручную после завершения сеанса. Встроенная установка обновлений доступна в Windows.

На Linux нужны совместимая glibc, настольная сессия и OpenGL. Не все дистрибутивы или их старые версии проверены. Инструкция для Debian/Ubuntu и ограничения других дистрибутивов находятся в README репозитория. macOS-сборки пока без подписи Apple Developer и нотарификации.
