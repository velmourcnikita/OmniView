# Архитектура

```text
Rust Core ── TLS / bounded packets ── Rust Core
    │                                  │
    └── system WebView2 ── HTML/CSS/JS ┘
```

`src/classroom.rs` отвечает за приглашение, TLS, участников, сообщения и bounded-очереди. `src/capture.rs` делает снимок основного монитора, уменьшает его и кодирует JPEG в памяти. `src/app.rs` связывает состояние с интерфейсом и сохраняет настройки. `wry + tao` встраивают локальный интерфейс в системный WebView2.

Кадры не записываются на диск. WebView загружает их отдельным endpoint по номеру последовательности, поэтому JSON-состояние не таскает большие base64-строки при каждом обновлении.
