# Пример урока

<DemoPanel />

Это локальный пример вопросов и ответов. Для проверки сетевых функций запусти программу на двух компьютерах.

## Сценарий показа

1. Учитель задаёт пароль класса и открывает сеанс.
2. Ученик вводит защищённый код и пароль.
3. Учитель публикует вопрос в «Задания и результаты».
4. Ученик выбирает ответ. Учитель завершает вопрос и показывает распределение.
5. Учитель сохраняет отчёт и открывает его в браузере для печати.
6. Ученик включает показ экрана. Учитель открывает карточку и отправляет сообщение.
7. Для самостоятельной работы учитель задаёт список процессов; ученик явно подтверждает проверку.

Данные на скриншотах подготовлены для иллюстрации интерфейса. Они не являются результатами испытаний в школе.
