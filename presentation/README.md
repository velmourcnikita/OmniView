# Презентация OmniView 0.5.1

Актуальные материалы:

- [Презентация, 12 слайдов](output/OmniView-0.5.1-Presentation.pptx).
- [Текст выступления](output/Текст%20выступления%200.5.1.txt).
- [Анимация программы](output/OmniView-0.5.1-Demo.gif).

На слайде 12 встроена GIF-анимация. Для воспроизведения включи показ слайдов. Если просмотрщик показывает только первый кадр, открой отдельный GIF в браузере.

Скриншоты и анимация показывают текущий интерфейс с демонстрационными участниками и тестовым обменом состояниями. Это не запись школьного урока. Проверки настоящего приложения описаны в [отчёте](../docs/verification-0.5.md).

Анимацию записывает `scripts/record-demo.cjs`: нужен Playwright, браузер Chromium и его FFmpeg-компонент. Для GIF используется FFmpeg: 8 кадров/с, ширина 1120 px. В полном ZIP также есть исходные скрипты сборки презентации, шрифты и предыдущие версии материалов.
