БЫСТРЫЙ СТАРТ

Подключение

На компьютере учителя

  1. Подключи компьютеры к одной локальной сети.
  2. Нажми «Открыть класс».
  3. Скопируй код и передай ученикам.
  4. Дождись подключений в обзоре класса.

На компьютере ученика

  1. Открой OmniView-Student.exe.
  2. Введи имя и код от учителя.
  3. Нажми «Подключиться».
  4. При необходимости включи показ своего экрана.

Если соединение не устанавливается

Проверь IPv4-адрес учителя в настройках и доступность компьютеров в одной сети. Windows может запросить разрешение для приложения в частной сети. После завершения класса старый код перестаёт действовать.

Для запуска нужны Windows 10 (x86 или x64) / Windows 11 и Microsoft Edge WebView2 Runtime. Звук не передаётся. Управление мышью и клавиатурой доступно с отдельного согласия ученика.
