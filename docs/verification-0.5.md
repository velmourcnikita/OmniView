# Локальные проверки 0.5.1

Проверено 2 ноября 2026 года на одном компьютере с 64-битной Windows. x86 запускалась под WoW64.

| Проверка | x64 | x86 |
| --- | --- | --- |
| Unit/integration tests | 17 passed | 17 passed |
| TLS, приглашение с паролем, сообщения и помощь | passed | passed |
| Вопрос, ответ, закрытие и раскрытие ключа | passed | passed |
| Обнаружение собственного процесса после согласия и отзыв при смене списка | passed | passed |
| Показ экрана в обе стороны и его выключение | passed | passed |
| Запрос управления, отдельное согласие, отзыв и остановка при выключении показа | passed | passed |
| Настоящий WebView и IPC | passed | passed |
| Уведомление: без системной рамки, видно перед 5 секундами, скрыто после таймера | passed | passed |
| Свойства EXE и SHA-256 | passed | passed |

Сетевые тесты управления передают события через настоящий TLS, но не выполняют их в посторонних приложениях. Рабочий поток проверяет согласие пустыми пакетами ввода.

Отдельный --control-test выполняет настоящий ввод только в собственном окне на переднем плане. Обе сборки, x64 и x86, прошли полный прогон: перемещение, клик, Unicode и Backspace. Потеря фокуса прерывает проверку без отправки ввода; действия пользователя могут мешать измерению.

Playwright проверяет запрос, согласие, остановку, координаты относительно изображения, текст, клавиши и доступность кнопки остановки при ширине 820 px. Скриншоты интерфейса используют подготовленные данные. Они не показывают урок в школе.

Сайт: сборка, интерактивный пример, изображения, подпись OmniCONTROL и ширины 1365/390 px. GitHub Actions и подтверждение происхождения релиза следует оценивать по соответствующему запуску в репозитории.

Нужны испытания между двумя физическими ПК, на старом оборудовании, настоящей x86 Windows и в полном классе. Защищённые и повышенные окна Windows, звук и дополнительные мониторы не поддерживаются.
