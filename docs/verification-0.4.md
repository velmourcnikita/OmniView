# Локальные проверки 0.4.0

Проведены 2 ноября 2026 года на одном компьютере с 64-битной Windows. x86 проверялась под WoW64.

| Проверка | x64 | x86 |
| --- | --- | --- |
| Rust unit/integration tests | 13 passed | 13 passed |
| TLS-паринг и отклонение неверного кода | passed | passed |
| OV3: пароль, повреждение кода, случайность конверта | passed | passed |
| Задание, ответ, подтверждение и раскрытие после завершения | passed | passed |
| Обнаружение собственного тестового EXE после согласия | passed | passed |
| Отзыв согласия при изменении списка | passed | passed |
| Показ своего экрана ученик ↔ учитель и выключение | passed | passed |
| Настоящий WebView: интерфейс и IPC | passed | passed |
| Собственное окно уведомления и захват его поверхности | passed | passed |
| Поля CompanyName и FileDescription | OmniCONTROL / подразделение | OmniCONTROL / подразделение |
| SHA-256 из манифеста | passed | passed |

Playwright отдельно проверил формы, отправляемые IPC-команды, поиск, фильтры, сохранение вопроса, блокировку повторного ответа, согласие на проверку, режим проектора, уменьшение движения и минимальную ширину окна. Эти проверки используют тестовые данные, а не реальную сеть.

Статический сайт собирается без SSR-ошибок. Проверены пример вопроса, изображение, подпись OmniCONTROL, отсутствие технических ярлыков на главной, ширины 1365 и 390 px.

GitHub Actions надо оценивать по фактическому запуску в репозитории. Локальная проверка YAML не заменяет запуск workflow.

Не проведены: полный класс, испытание между двумя физическими ПК, замеры на старом железе, реальная x86 ОС, педагогическая апробация. Результаты этих испытаний не подменены тестовыми данными.
