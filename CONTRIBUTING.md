# Работа с кодом

Изменения отправляются через pull request с описанием поведения и проверок. Для сетевых изменений добавляй проверку ограничения размеров и отказа при некорректных данных. Нельзя включать скрытый мониторинг, автозапуск или передавать весь список процессов.

Перед отправкой: `cargo fmt --check`, `cargo test --locked`, сборка x86/x64 и `npm ci && npm run build` в `site/`.

История Git начинается с момента создания репозитория. Предыдущая работа не представлена как серия вымышленных коммитов. Использование помощников при разработке не заменяет понимание кода автором: на защите нужно самостоятельно объяснить протокол, согласие и ограничения.
